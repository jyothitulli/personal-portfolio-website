# Personal Portfolio

A modern developer portfolio built to showcase my projects, technical skills, coding profiles, internship experience, and overall software engineering journey.

The portfolio is designed with a clean UI, responsive layout, smooth animations, dark/light theme support, and interactive sections to create a more professional and engaging experience.

 

## Features

- Responsive modern UI
- Dark / Light theme toggle
- Interactive project showcase
- Coding profiles section
- Internship & experience section
- Contact form integration
- Hover animations and glowing effects
- Smooth scrolling experience
- Mobile responsive navigation
- Resume download support

## Installation

Clone the repository:

  
git clone https://github.com/jyothitulli/ personal-portfolio-website.git
 

Move into the project folder:
 
cd  personal-portfolio-website
 
Install dependencies:
npm install
 

Start development server:

  
npm run dev
 

 

## Environment Variables

Create a `.env` file in the root directory and add:

 env
VITE_EMAILJS_SERVICE_ID=service_9ualmto
VITE_EMAILJS_TEMPLATE_ID=template_oxym4ea
VITE_EMAILJS_PUBLIC_KEY=oms4JXuKulypzRlp2
 

 

## Build For Production

npm run build
